# Imagens das linhas de trabalho — TEU7VD

14 imagens WebP preparadas para `assets/giras/`. Inclui a composição corrigida de **Pombagiras e Exús**, com os dois arquétipos lado a lado.

## Mapa
- Pretos Velhos → `pretos-velhos.webp`
- Caboclos → `caboclos.webp`
- Malandros → `malandros.webp`
- Pombagiras e Exús → `pombagiras-exus.webp` (imagem corrigida e aprovada)
- Pombagiras → `pombagiras.webp`
- Exús → `exus.webp`
- Marinheiros → `marinheiros.webp`
- Erês → `eres.webp`
- Baianos → `baianos.webp`
- Boiadeiros → `boiadeiros.webp`
- Exú Mirim e Pombagira Mirim → `exus-mirim-pombagiras-mirim.webp`
- Ciganos → `ciganos.webp`
- Cirurgia Espiritual → `cirurgia-espiritual.webp`
- Gira Pet → `gira-pet.webp`

O código de associação usa `titulo` e `tipo_gira`, normaliza acentos e variações de singular/plural e prioriza as categorias combinadas antes das categorias individuais. Portanto, mudanças cosméticas no nome dos cards não alteram a imagem correspondente.

## Instalação
Copie todos os arquivos desta pasta para `assets/giras/` no repositório. Não renomeie os arquivos. O código da agenda já está preparado na branch `feat/giras-real-images-assets` para carregar `assets/giras/{categoria}.webp`.
